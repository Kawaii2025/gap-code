# GapCode - 填空式算法刷题平台

This is a React + TypeScript + Vite project converted from raw.html.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Features
- Problem list page
- Solve page with Monaco code editor
- Light/Dark theme toggle
- Simple judge logic
